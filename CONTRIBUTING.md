# Contributing

1. Create a focused topic branch.
2. Follow the layout and conventions documented in this repository.
3. Add or update checked-in fixtures under `tests/fixtures/` for tests that consume
   executable, disc, header, CUE, or other external file data. Fixture-based tests
   are mandatory; do not synthesize fixture input in test code.
4. Build and run tests before submitting changes.
5. Document format or platform gaps under `docs/dev/debt/`.
